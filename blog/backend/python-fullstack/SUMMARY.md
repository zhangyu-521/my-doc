## 🎯 核心技术栈

- **SQLAlchemy** - ORM 数据库操作
- **Pydantic** - 数据验证

### 数据存储
- **PostgreSQL** - 关系型数据库
- **Redis** - 缓存与任务队列
- **Qdrant** - 向量数据库

### AI 集成
- **OpenAI API** - LLM 接口
- **DeepSeek** - 国产大模型
- **RAG** - 检索增强生成
- **Function Calling** - Agent 工具调用

- **Docker** - 容器化
- **Nginx** - 反向代理
- **Let's Encrypt** - SSL 证书
- **Gunicorn** - WSGI 服务器
