# Python 全栈开发 - 前端工程师转型指南

## 写给谁？

如果你是前端工程师，想学习 Python 后端开发，尤其是为了进入 AI 应用开发领域，这个系列就是为你准备的。

::: tip
这不是一个从零开始的 Python 教程。我假设你已经会 JavaScript，能快速理解编程概念。我会重点讲**差异**和**实战**，而不是基础语法。
:::

## 为什么要学 Python 全栈？

### 市场现状
- **前端岗位饱和** - 竞争激烈，门槛越来越高
- **AI 赛道增长** - 大量 AI 创业公司需要全栈工程师
- **复合型人才稀缺** - 既懂前端交互，又能开发 AI 后端的人不多

### 你的优势
作为前端工程师，你已经有：
- **编程基础** - 理解变量、函数、异步等核心概念
- **工程化思维** - 会用构建工具、版本管理、代码规范
- **产品思维** - 懂用户体验，知道如何做好一个产品

现在只需要补充：
- Python 后端开发能力
- 数据库操作与设计
- AI 能力集成（LLM、Agent）

## 学习建议

### 环境准备
- **Python 3.11+** - 推荐使用最新稳定版
- **VSCode** - 你已经熟悉的编辑器
- **PostgreSQL** - 生产环境常用数据库（也可以先用 SQLite）

### 学习节奏
- **每章预计 2-3 小时** - 包括阅读、敲代码、调试
- **建议每天 1-2 小时** - 保持连续性，不要断太久
- **必须动手实践** - 只看不写学不会

### 遇到问题怎么办
1. 先看报错信息，Google 搜索
2. 检查代码拼写、缩进（Python 对缩进严格）
3. 用 `print()` 调试变量值
4. 实在不行就先跳过，往后学可能就懂了

## 技术栈对照

从前端到 Python 后端，你会发现很多相似之处：

| 前端 | Python 后端 | 用途 |
|------|-------------|------|
| Express.js | FastAPI | Web 框架 |
| Axios | httpx | HTTP 客户端 |
| npm/pnpm | pip/poetry | 包管理器 |
| TypeScript | Type Hints | 类型系统 |
| Jest | pytest | 测试框架 |
| ESLint | ruff | 代码检查 |
| Webpack | - | (Python 不需要打包) |
