# Python 流程控制语句

流程控制语句（Flow Control Statements）是编程语言中最基础、也最重要的语法组成部分。程序并不总是简单地"从上到下、逐行执行"——它需要根据条件做出判断、在某些情况下重复执行相同的操作、或在满足特定条件时提前跳出。这些用来控制程序执行顺序与流向的语句，统称为流程控制语句。掌握流程控制语句，是写出任何有实际功能的程序的第一步。

::: tip
顺序、选择、循环是程序世界的三大基石。
:::

## 1. 程序的三种基本结构

任何复杂的程序，都可以由三种基本结构组合而成：顺序结构、选择结构和循环结构。三种结构对应了流程控制语句的全部职能。

- **顺序结构**：语句按照书写顺序从上到下依次执行，是最自然、最基础的结构。
- **选择结构**：根据条件的真假，决定执行不同的分支。
- **循环结构**：在条件成立时，重复执行某段代码。

## 2. 顺序结构

顺序结构是程序最默认的执行方式：从上到下、逐条执行，前一条语句执行完毕后，才会执行下一条。它是所有程序的基础骨架。

```python
# 顺序结构：语句按书写顺序依次执行
a = 1
b = 2
c = a + b
print(c)  # 输出 3
```

## 3. 选择结构

### 3.1 逻辑运算符与比较运算符

条件判断的核心是比较运算与逻辑运算：比较运算符用来比较两个值的关系（如相等、不等、大小），逻辑运算符用来把多个条件组合起来（如"并且""或者""取反"）。两者的结果都是布尔值 `True` 或 `False`，是组成 `if`、`while` 等条件的关键。

当需要同时或选择性地判断多个条件时，使用逻辑运算符：

- `and`（且）：所有条件都为真时，结果才为真。
- `or`（或）：任一条件为真，结果即为真。
- `not`（非）：对单个条件取反，真变假、假变真。

```python
age = 20
has_id = True

# and：两个条件都成立才执行
if age >= 18 and has_id:
    print("可以进入")   # 输出：可以进入

# or：任一条件成立即执行
if age < 12 or has_id:
    print("条件成立")   # 输出：条件成立

# not：对条件取反
if not has_id:
    print("请出示证件")
```

### 3.2 if 语句

最简单的选择结构：条件为真时，执行紧随其后的代码块；条件为假时，直接跳过。

```python
age = 18
if age >= 18:
    print("已成年")
```

### 3.3 if-else 语句

在 `if` 的基础上增加 `else` 分支：条件为真执行 if 分支，条件为假执行 else 分支，二者必居其一。

```python
score = 75
if score >= 60:
    print("及格")
else:
    print("不及格")
```

### 3.4 else if / elif 多分支

当需要依次判断多个条件时，可以使用 else if（Python 中写作 `elif`）。程序按顺序逐个判断，命中第一个为真的分支后立即结束判断。

```python
score = 85
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

### 3.5 嵌套 if

`if` 语句内部可以再嵌套 `if`，用于表达更复杂的判断逻辑。嵌套虽然灵活，但层级过深会显著降低代码可读性，建议控制在两到三层以内。

```python
age = 20
has_id = True
if age >= 18:
    if has_id:
        print("可以进入")
    else:
        print("请出示证件")
else:
    print("未成年，禁止进入")
```

### 3.6 match 语句

当需要对同一个变量的多个取值做等值判断时，`match` 比一长串 if-else 更清晰、执行效率也更高。

```python
day = 3
match day:
    case 1:
        print("周一")
    case 2:
        print("周二")
    case _:
        print("其他")
```

### 3.7 条件表达式（三元运算符）

当分支逻辑只有一行且需要作为表达式参与赋值时，可以使用条件表达式。Python 与 C 系语言的写法不同，但语义一致。

```python
score = 75
result = "及格" if score >= 60 else "不及格"
print(result)
```

## 4. 循环结构

循环让程序可以重复执行某段代码，直到条件不再成立或通过跳转语句显式退出。循环是处理批量数据、遍历集合、实现算法的基础。

### 4.1 while 循环

先判断条件，条件为真才执行循环体；每执行完一轮，再次回到条件判断。如果条件一开始就不成立，循环体一次也不会执行。

```python
i = 1
while i <= 5:
    print(i)
    i += 1
```

### 4.2 for 循环

`for` 循环把"初始化、条件判断、步进更新"集中在一行，适合循环次数确定的场景。Python 使用 `range` 实现等价的计数循环。

```python
for i in range(1, 6):
    print(i)
```

`for` 循环也常用于遍历数组（Python 中叫列表 `list`）：

```python
fruits = ["苹果", "香蕉", "橙子"]
for fruit in fruits:
    print(fruit)  # 直接遍历元素

# 也可以按索引遍历，同时拿到下标
for i in range(len(fruits)):
    print(i, fruits[i])

# 更简洁：用 enumerate 同时拿到下标和元素
for i, fruit in enumerate(fruits):
    print(i, fruit)
```

### 4.3 嵌套循环

循环内部再套循环，常用于二维数据的遍历（如矩阵、表格）。外层循环每执行一轮，内层循环完整执行一遍。

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)
```

### 4.4 如何选择循环

- 循环次数确定：优先使用 `for` 循环。
- 只知结束条件、不知次数：使用 `while` 循环。

## 5. 跳转语句

跳转语句用于在循环或函数内部改变执行流，让程序能够在特定条件下提前退出或跳过。

### 5.1 break

立即终止当前所在的最内层循环，程序继续执行循环之后的语句。

```python
for i in range(1, 10):
    if i == 5:
        break
    print(i)  # 输出 1、2、3、4
```

### 5.2 continue

跳过本次循环体中 `continue` 之后的语句，直接进入下一轮循环。

```python
for i in range(1, 6):
    if i % 2 == 0:
        continue
    print(i)  # 输出 1、3、5
```

### 5.3 return

结束当前函数的执行，并（可选的）返回一个值给调用方。函数内一旦执行到 `return`，其后的代码不再运行。

```python
def max_value(a, b):
    if a > b:
        return a
    return b
```

### 5.4 goto（了解即可）

`goto` 是无条件跳转语句，可以直接跳到程序中的任意标签处。它的自由度太高，滥用会严重破坏程序结构、使代码难以理解和维护，因此主流现代语言（如 Python、Java）都不再提供，C 语言虽保留但也不推荐使用。

## 6. 主流语言语法对比

| 语言 | 条件分支 | 循环 | 其他特点 |
| --- | --- | --- | --- |
| Python | if / elif / else | for、while | 无 switch，可用字典映射替代 |
| Java | if / else if / else、switch | for、while、do-while、for-each | switch 支持字符串与枚举 |
| C | if / else、switch | for、while、do-while | 支持 goto，语法最基础 |
| JavaScript | if / else、switch、三元运算符 | for、for-of、while、do-while | 前端必用，注意类型比较 |

## 7. 常见错误与最佳实践

### 7.1 常见错误

- **死循环**：循环体内忘记更新循环变量，导致条件永远为真。例如下面的代码会无限输出，直到程序被强制终止：

```python
i = 1
while i <= 5:
    print(i)      # 忘记写 i += 1，循环无法结束
```

- **switch 漏写 break**：分支穿透，执行了不该执行的分支。
- **判断相等误用赋值**：在 C / Java 中把 `if (a == b)` 误写成 `if (a = b)`，条件表达式变为赋值，逻辑完全错误。
- **边界条件搞错**：混淆 `<` 与 `<=`，导致多执行一次或少执行一次，尤其在遍历数组时容易下标越界。
- **嵌套过深**：多层 if / 循环嵌套使代码难以阅读和调试。

### 7.2 最佳实践

- 条件表达式保持简单直观，优先使用明确的比较运算，避免双重否定等绕弯写法。
- 善用"早返回"：在函数开头先处理异常或边界情况，用 `return` 提前退出，减少嵌套层级。
- 循环体内避免不必要的重复计算，可将不变的表达式提到循环外。
- 变量命名清晰，循环变量使用有意义的名称（如 `i`、`j` 之外，可用 `index`、`count`）。
- 遍历集合时优先使用语言提供的增强 for 或迭代器，减少手写下标出错的可能。

## 8. 总结

顺序、选择、循环是程序世界的三大基石，跳转语句则是对它们的灵活补充。学习流程控制语句时，不必死记每种语言的语法，而应首先理解"程序如何按条件流动"这一核心思想——一旦理解了结构与流程，再换任何一门语言，都只是语法外形不同而已。
