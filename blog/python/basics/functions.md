# Python 函数入门

## 什么是函数？

函数就是把一段代码"打包"起来，给它起个名字。以后想用的时候，直接喊名字就行，不用再写一遍。

就像去奶茶店点单，你不需要每次都跟店员解释"我要一杯珍珠、三分糖、去冰的奶茶"，直接说一句"珍珠奶茶三分糖去冰"，店员马上懂。函数就是你的"快捷点单口令"。

::: tip
不想重复写一样的代码，就把它装进函数里。
:::

## 为什么需要函数？

- 不想重复写一样的代码，写两遍就烦，写十遍会疯
- 改需求只改一个地方，别处自动跟着变
- 代码看起来清爽，过几天回来看也认得

## 函数长什么样？

先看个最简单的结构：

```python
def 函数名(参数):
    # 里面写要干的事
    return 结果
```

拆开看：`def` 是"定义函数"的关键字，函数名自己起，括号里放参数（没有参数就空着），冒号结尾，缩进的那几行就是函数每次要做的事，`return` 把结果交出来。

## 没想好写啥？用 pass 占个位

有时候先搭好函数的名字，里面具体写啥还没想好，直接空着会报错。这时候就用 `pass` 占个位，让代码先能跑起来：

```python
def 我嘞个豆():
    pass

我嘞个豆()   # 啥也不干，但不会报错
```

`pass` 就是"占位符"，相当于给函数挂个"装修中"的牌子，里面先空着。等想好逻辑了，把 `pass` 换成真正的代码就行。

`pass` 不只是用来占住空函数，条件分支没想好怎么写时，也能先占着：

```python
def 检查分数(score):
    if score >= 60:
        pass    # 及格了先不处理，奖励还没想好
    else:
        print("不及格，下次加油！")

检查分数(80)   # 能跑，及格分支先空着
```

一次性搭好几个函数骨架、先让整个程序能跑起来，也常用 `pass` 占位：

```python
def 保存文件():
    pass   # 功能还没写

def 读取文件():
    pass   # 功能还没写

# 先把函数都列出来，后面一个个填
```

## 动手写一个

先写一个召唤非洲之心的函数，喊它就答应：

```python
def get_heart():
    print("非洲之心")

get_heart()   # 调用函数：喊它一次
get_heart()   # 继续召唤
```

输出：

```text
非洲之心
非洲之心
```

看到没，喊几次就答应几次，函数里的代码每次都重新跑一遍。

## 给函数加点参数

光会打招呼有点呆，加个参数，让它能叫出每个人的名字：

```python
def say_hello(name):
    print("你好呀，" + name + "！")

say_hello("小满")   # 输出：你好呀，小满！
say_hello("大满")   # 输出：你好呀，大满！
```

多个参数也行，用逗号隔开：

```python
def greet(name, age):
    print(f"{name}今年{age}岁")

greet("小满", 18)   # 输出：小满今年18岁
```

## 默认参数：不传也有值

有时候不想每次都传参数，可以给参数一个默认值，不传就自动用默认的：

```python
def say_hello(name="同学"):
    print("你好呀，" + name + "！")

say_hello()          # 输出：你好呀，同学！
say_hello("小满")    # 输出：你好呀，小满！
```

## 返回值：函数把结果交给你

有的函数不光"干活"，还会把结果"递"给你，用 `return`：

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)   # 输出：8
```

注意：如果函数里没有 `return`，它也会返回一个东西——`None`，相当于"什么也没给"。

## lambda 表达式：没有名字的函数

类似于前端的箭头函数精简版。除了 `def`，Python 还有一种"一句话"写法——`lambda`。它也是函数，但没有名字，所以叫"匿名函数"，适合那种一两行就能写完的小函数。

```python
lambda 参数: 表达式
```

冒号左边是参数，右边就是要返回的结果，连 `return` 都省了。比如"两数相加"，普通写法和 lambda 写法是一个意思：

```python
def add(a, b):
    return a + b

add2 = lambda a, b: a + b

print(add(3, 5))    # 输出：8
print(add2(3, 5))   # 输出：8
```

`lambda` 最常见的用法是"临时用一次"，比如给列表排序时指定按什么排：

```python
scores = [("小满", 88), ("阿强", 95), ("豆豆", 79)]
scores.sort(key=lambda item: item[1])
print(scores)   # 输出：[("豆豆", 79), ("小满", 88), ("阿强", 95)]
```

注意：`lambda` 只能写一个表达式，不能像 `def` 那样写好几行逻辑。逻辑一复杂，还是乖乖用 `def` 吧。

## 小练习

写一个函数，传入一个数字，判断是奇数还是偶数，奇数返回 `True`，偶数返回 `False`：

```python
def is_odd(n):
    if n % 2 == 0:
        return False
    return True

print(is_odd(3))   # 输出：True
print(is_odd(4))   # 输出：False
```
