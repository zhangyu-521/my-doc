# 微信小程序自动化发布文章设计

## 目标

在技术博客中发布一篇关于微信小程序自动化发布流程的文章，并提供清晰的“小程序”侧边栏入口。

## 内容与信息架构

- 新文章位于 `blog/myself/miniprogram/release-pipeline.md`，使用中文标题“微信小程序自动化发布：从本地上传到可控发布流水线”。
- 正文保留用户提供的流程说明、`miniprogram-ci` 示例、命令设计、权限边界和发布记录建议，并遵循仓库的 Markdown 写作规范。
- 在现有 `/blog/` 侧边栏的“zyDocs 博客”下新增一个默认折叠的“小程序”分组，链接到该文章；不新增顶级导航，以免单篇文章占用主导航空间。

## 安全边界

- 文章明确说明私钥不得提交仓库，且不会在仓库中新增任何真实 AppID、私钥或发布配置。
- 文中把上传、预览、审核和正式发布区分开来；生产发布必须有显式人工确认。

## 验证与交付

- 使用 `pnpm docs:build` 验证 VitePress 可构建，确认新页面和侧边栏配置无链接或 Markdown 解析错误。
- 仅提交本次新增的文章、侧边栏配置和设计文档；保留用户已有的未跟踪文件 `public/skills.png` 不提交。
- 提交到当前 `master` 分支后，现有 GitHub Actions 会自动构建并部署 GitHub Pages。
